# Серверная часть «Рядом»

```
cd 01_Прототип/server
ANTHROPIC_API_KEY=sk-... node server.js        # http://localhost:8787 — сайт + /api/dialogue
```
Если ключ задан, сервер сам подставляет в страницу `window.RYADOM_API` — диалог идёт через модель.
Без ключа (или при ошибке модели, таймауте 7 с, пустом ответе) работает диалог на правилах.

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ (обязателен для модели) |
| `ANTHROPIC_MODEL` | модель, по умолчанию `claude-sonnet-5-5` |
| `ANTHROPIC_BASE_URL` | для тестов и прокси |
| `PORT` | порт, по умолчанию 8787 |
| `ALLOW_ORIGIN` | CORS, если страница на другом домене |
| `TELEGRAM_BOT_TOKEN` | включает Telegram-бота (токен от @BotFather) |
| `TELEGRAM_ALLOWED_IDS` | необязательно: id чатов через запятую (закрытый тест) |

## Что делает сервер
- Явные фразы о вреде себе/другим и о небезопасной обстановке в модель не уходят: сразу ответ `risk`.
- Правила риска — общий файл `dist/risk.js` (для страницы и сервера); проверяются `tests/safety-cases.json`.
- Модель отвечает структурой через tool-call; сервер проверяет `risk`, `suggestedPracticeId` по каталогу, отбрасывает ответы с диагнозами и лекарствами.
- В модель уходят: последние реплики (до 12), профиль «Обо мне» (если включён) и последние отметки состояния. Профиль подаётся как данные, а не как команды.
- Тексты разговоров не логируются и не хранятся. Ограничение частоты — 20 запросов в минуту на адрес.

## Свободная репетиция (`POST /api/rehearse`)
Тело: `{ persona:{name,style,situation}, messages:[{role,text}], mode:'play'|'coach' }`. `play` — модель отвечает в роли собеседника
(1–3 реплики, без оскорблений, угроз и советов), `coach` — короткий разбор формулировок (что получилось, что попробовать, вариант фразы).
Описание роли подаётся как данные, а не как команды; явный риск в реплике пользователя в модель не уходит. Карточка «Репетиция своими словами»
появляется на странице, только если сервер подставил `window.RYADOM_API.rehearse` (то есть задан ключ). Без сервера работают готовые тренажёры.
Проверка: `node tests/mock-anthropic.js &` (порт 9912), затем `ANTHROPIC_API_KEY=k ANTHROPIC_BASE_URL=http://localhost:9912 PORT=8789 node server.js`
и `node tests/rehearse-e2e.js` (нужен `playwright`).

## Telegram
`TELEGRAM_BOT_TOKEN=... ANTHROPIC_API_KEY=... node server.js`. Команды: `/start`, `/help`, `/forget`. История — только в памяти процесса,
стирается через 24 часа или командой. Двусмысленная фраза → прямой вопрос; явный риск → текст с номером 112. Бот без профиля и практик (это следующий шаг).

## Тесты безопасности
`node tests/run-safety.js` (клиентская часть требует `playwright` и сервер на :4173). Любое изменение правил — вместе с новыми случаями.

## Установка на телефон
Страница — PWA (`manifest.webmanifest`, `sw.js`): с адреса `https://` или `localhost` в браузере телефона «Добавить на главный экран».
Мягкие напоминания (push) требуют аккаунта и серверной части отправки — пока не сделаны.

Перед выпуском: политика данных, экспертное ревью сценариев безопасности и юридическая проверка.
