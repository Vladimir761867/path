# 07. Целевая архитектура и данные

## Контуры

Мобильный клиент/PWA ↔ собственный API ↔ защищённая БД. За API: диалоговый оркестратор и журнал версий, каталог практик, игровой контент, адаптер мест, учёт согласий, экспорт/удаление. Поставщики ИИ, карт и голоса подключаются сервером через сменяемые адаптеры. Рекомендации и опасные сценарии проверяются отдельно от генерации текста.

## Минимальные сущности

| Сущность | Ключевые поля | Замечание |
|---|---|---|
| User/Consent | `user_id`, язык, часовой пояс, согласия и версии | Анонимный режим — отдельное решение |
| Conversation/Message | `conversation_id`, время, роль, текст, версия политики | Хранение текста только по согласию |
| Checkin | локальная дата, тревога, грусть, беспокойство, спокойствие, заметка | Не диагноз |
| Practice/PracticeRun | версия карточки, выбранный шаг, субъективный исход | Личный текст практики по умолчанию не сохранять |
| Place/Visit/Favorite | ID источника, координаты, дата визита, ощущение, признак любимого | GPS ≠ доказанное посещение |
| GameStory/GameSession | версия сюжета, глава, решения, флаги и маршрут | Отдельно от дневника |
| Audit/Deletion | журнал доступа и запросов удаления | Без содержания чувствительного текста в обычных логах |

Образцы машинного формата в `03_Схемы`. Их надо превратить в валидируемые схемы API и миграции БД при реализации.

## API первого релиза (предложение)

`POST /conversations`, `POST /conversations/{id}/messages`, `GET/DELETE /conversations/{id}`; `GET/PUT /checkins/{local_date}`; `GET /practices`, `POST /practice-runs`; `GET/POST/PATCH/DELETE /visits`; `GET/POST/DELETE /favorites`; `GET /places/search?mood&lat&lon` или ручной район; `GET /games/{id}`, `GET/PUT /game-sessions/{id}`; `GET /me/export`, `DELETE /me/data`, `GET/PUT /me/consents`. Это проектные контракты, не существующие endpoints.

## Защита и эксплуатация

Минимизация данных, шифрование в пути и на хранении, секреты на сервере, доступ по ролям, ограничение запросов, мониторинг ошибок без текстов личных разговоров, резервирование и проверенное восстановление, версионирование политик и контента, тесты миграций. Перед запуском определить юрисдикции, основания обработки, срок хранения и поставщиков. Для рейтингов/соцданных проверить права на показ и кеширование. Данные тестового браузерного прототипа не переносить на сервер автоматически.
