# «Рядом» — мобильное приложение (Android и iOS)

Нативная оболочка на [Capacitor 8](https://capacitorjs.com/) вокруг веб-версии из `01_Прототип/dist`.
Весь интерфейс, диалог, квесты и практики — те же файлы; приложение добавляет то, чего нет у сайта.

## Что есть только в приложении (`native/native.js`)
| Функция | Как работает |
|---|---|
| Надёжное хранение | Данные дублируются в нативное хранилище (Preferences). Если система очистит память WebView, при запуске всё восстановится. «Удалить все мои данные» стирает и копию. |
| Кнопка «назад» (Android) | Закрывает окно / подтверждение → выходит из квеста → возвращает на «Сегодня» → сворачивает приложение. |
| Напоминание | В «Обо мне» → «Напоминание»: раз в день в выбранное время. Локальное уведомление, без сервера и интернета. |
| Экспорт данных | «Сохранить копию файлом» открывает системное «Поделиться» (Файлы, облако, мессенджер себе). |
| Иконка, заставка, статус-бар | В цветах приложения, светлая и тёмная заставка. |
| Тактильная отдача | Лёгкая вибрация на кнопках ответа и навигации. |
| Приватность Android | Резервное копирование в облако Google и перенос на новое устройство **отключены** для данных приложения — данные о состоянии не покидают телефон без явного экспорта. |
| Разрешения | Интернет; примерное местоположение (только по кнопке «Рядом со мной»); уведомления (только при включении напоминания). |

Сервис-воркер и манифест PWA в приложение не попадают — обновления приходят вместе с новой версией приложения.

## Где взять готовый APK
Каждый push в `main` запускает GitHub Actions (`.github/workflows/app.yml`):
- **Android**: собирает `ryadom-debug.apk` и публикует его в релизе **android-latest** репозитория — ссылку можно открыть прямо на телефоне, скачать и установить (разрешить «установку из этого источника»).
- **iOS**: проверяет, что проект компилируется для симулятора. Установка на iPhone требует Mac или облачной подписи (см. ниже).

## Сборка у себя
Нужно: Node.js 22+, для Android — Android Studio (JDK 21, SDK 36), для iOS — Mac с Xcode 16+.
```bash
cd РЯДОМ/03_Приложение
npm install
npm run android     # собрать веб-часть, синхронизировать и открыть Android Studio
npm run ios         # то же для Xcode (только на Mac)
npm run apk         # debug-APK из командной строки → android/app/build/outputs/apk/debug/
```
После любых правок в `01_Прототип/dist` достаточно `npm run sync`.

### Подключить сервер с ИИ (живой диалог и репетиция)
```bash
RYADOM_API_URL=https://ваш-сервер npm run sync
```
На сервере (`server/`) добавьте источники приложения в `ALLOW_ORIGIN`: `https://localhost` (Android) и `capacitor://localhost` (iOS).
В GitHub Actions адрес берётся из переменной репозитория `RYADOM_API_URL` (Settings → Secrets and variables → Actions → Variables).

### Иконки и заставки
Исходники — `assets/` (рисуются скриптом `node scripts/make-icons.js`). После замены: `npm run icons`.

## Подписанный релиз для магазинов
1. Создать ключ **один раз и хранить надёжно** (потеря ключа = невозможность обновлять приложение):
   ```bash
   keytool -genkeypair -v -keystore ryadom-release.jks -alias ryadom -keyalg RSA -keysize 2048 -validity 10000
   ```
2. В GitHub → Settings → Secrets and variables → Actions → **Secrets** добавить:
   `ANDROID_KEYSTORE_BASE64` (вывод `base64 -w0 ryadom-release.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (`ryadom`), `ANDROID_KEY_PASSWORD`.
3. Следующая сборка дополнительно выпустит `ryadom-release.apk` (для RuStore) и `ryadom-release.aab` (для Google Play).

Номер сборки (`versionCode`) растёт автоматически; версия для людей — `versionName` в `android/app/build.gradle`.
Идентификатор приложения — `ru.ryadom.app` (`capacitor.config.json`); поменять его можно только до первой публикации.

## iOS
- Нужен аккаунт Apple Developer и Mac (или облачная сборка с подписью: Xcode Cloud, Codemagic, Ionic Appflow).
- В `ios/App/App/Info.plist` уже есть русская локализация, текст запроса геолокации и отметка об отсутствии собственного шифрования.
- Голосовой ввод в WebView iOS/Android обычно недоступен — кнопка микрофона в этом случае отключается сама.
