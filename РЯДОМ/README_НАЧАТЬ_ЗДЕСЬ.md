# Приложение «Рядом» — пакет для разработки

Версия пакета: 9 ноября 2026 года. Опубликованный прототип: https://ryadom-everyday-mentor.silverinn2.chatgpt.site
Исходная версия прототипа: commit `13847d9af59894a821816d004d78a3c6116a016a`.

## С чего начать

1. Откройте `02_Документация/01_Продукт.md` — что должно делать приложение и как связаны разделы.
2. Запустите прототип из `01_Прототип/dist` по инструкции ниже. Не открывайте `index.html` напрямую через `file://`: некоторые браузерные возможности требуют локального сервера.
3. Прочитайте `02_Документация/02_Текущее_состояние_и_ограничения.md`. Код — демонстрация сценариев и дизайна, а не готовая архитектура продукта.
4. Для оценки объёма работ используйте архитектуру, модели данных, контентные спецификации и критерии приёмки в остальных документах.

## Запуск на Windows

Дважды нажмите `Запустить_на_Windows.bat` (понадобится установленный Python 3) и откройте http://localhost:4173. Если команда `py` недоступна, выполните в терминале из этой папки:

```powershell
python -m http.server 4173 --directory "01_Прототип/dist"
```

На macOS/Linux: `python3 -m http.server 4173 --directory 01_Прототип/dist`.

## Состав папки

- `01_Прототип/` — полные исходные файлы опубликованного адаптивного веб-прототипа, стили, сценарии, изображения и конфигурация хостинга.
- `02_Документация/` — продуктовая спецификация, аудит текущего кода, целевой диалог, практика, игра, места, данные, план реализации и тестирование.
- `03_Схемы/` — пример структуры сущностей и примеры контрактов для будущего API. Это проектные примеры, не уже работающий сервер.
- `Запустить_на_Windows.bat` — запуск локального просмотра.

## Что действительно работает сейчас

Дневник и календарь, отметки состояния, библиотека практик, пример подробной практики, диалог со свободным текстом и отражением сказанного (`dialogue-v2.js`), две сюжетные игры на общем движке — «Тихий город» и «Границы без ссоры» (`game-v2.js` + `stories/*.json`), восемь квестов-тренажёров трудных разговоров, маршруты практик и блок «Подходит сейчас», короткие игровые зарисовки, голосовая диктовка браузера, ручная запись посещённых мест, любимые места, поиск новых мест по настроению и геолокации/городу. Записи сохраняются только в `localStorage` этого браузера. Поиск новых мест использует публичные данные OpenStreetMap через Photon и может быть недоступен или неполон.

## Сервер, Telegram, телефон

Подробности — `01_Прототип/server/README.md`: `ANTHROPIC_API_KEY=... node server.js` включает диалог на модели (сайт откроется на http://localhost:8787), `TELEGRAM_BOT_TOKEN` — Telegram-бота. Страница устанавливается на телефон как PWA. Тесты безопасности: `node 01_Прототип/tests/run-safety.js`. Свободная репетиция с моделью (`/api/rehearse`) включается тем же ключом. Перед выпуском: `02_Документация/06_Для_психолога.md`.

## Что потребуется разработать отдельно

Сервер, аккаунты и синхронизация, защищённое хранение и удаление, управляемый ИИ-диалог, полноценный голосовой разговор, редактор контента, экспертная проверка практик, полноценные игровые механики и иллюстрации, надёжный поставщик данных о местах, рейтинги и легально доступные сигналы из соцсетей, аналитика качества и безопасности. В прототипе нет медицинской валидации и гарантий эффекта.

## Решение по продукту

Взрослое приложение для повседневной эмоциональной поддержки. Оно не выдаёт себя за человека и не обещает терапию или «сепарацию» после игры. Игровой прогресс, личный дневник и поиск мест — разные контуры данных. Пользователь решает, что сохранять и чем делиться.


## Языки
15 языков интерфейса: русский, английский, испанский, французский, немецкий, португальский, турецкий, казахский, грузинский, арабский (справа налево), китайский, японский, хауса, суахили, йоруба. Выбор — на вводном экране, вверху страницы и в «Обо мне»; по умолчанию берётся язык телефона.
- Словари: `01_Прототип/dist/i18n/<код>.js`. Ключ — исходная русская строка, поэтому код приложения почти не менялся. Переводчик страницы — `i18n.js`. Строки без перевода видны в консоли: `[...RyadomI18n.missing]`.
- Диалог на других языках (`dialogue-intl.js`): подсказки-кнопки и распознавание простых слов. С сервером ИИ модель отвечает на выбранном языке полностью.
- Безопасность: слова о риске распознаются на всех языках (`risk.js`), показываются 112, местные линии помощи и findahelpline.com.
- Квесты, сюжетные истории и зарисовки переведены на английский: `dist/quests/<код>/`, `dist/stories/<код>/`, тексты зарисовок — в словаре. Список языков с переведёнными квестами — `CONTENT` в `i18n.js`. На остальных языках квесты пока на русском, в «Играх» есть пометка.
- Переводы сделаны без носителей языка. Перед выпуском их нужно проверить, в первую очередь кризисные тексты и номера помощи.
- Тесты: `node 01_Прототип/tests/i18n-e2e.js` (все языки, сервер на :4173) и `node 01_Прототип/tests/risk-intl.js`.
